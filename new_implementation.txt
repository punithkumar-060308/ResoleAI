====================================================================
1. FINAL PROJECT VISION
====================================================================

PROJECT:
ResolveAI — Autonomous Customer Support Intelligence Platform

ONE-LINE PITCH:

ResolveAI turns every customer complaint into an investigation. It collects
context from multiple enterprise systems, routes the issue to the right
specialist agents, reasons over evidence using Qwen, identifies root causes,
takes safe actions automatically, and escalates risky/complex cases to a
human with complete context.

TRADITIONAL SUPPORT:

Customer -> Ticket -> Chatbot Answer

RESOLVEAI:

Customer
   ->
Understand
   ->
Route
   ->
Investigate
   ->
Collect Context
   ->
Reason over Evidence
   ->
Find Root Cause
   ->
Assess Risk
   ->
Decide
   ->
Act OR Escalate
   ->
Generate Context-Aware Response
   ->
Audit
   ->
Analytics

====================================================================

REQUIREMENT 1:
Autonomous Support Agent

IMPLEMENT:
The Orchestrator + Resolution workflow should be able to handle a complete
multi-step case instead of stopping after one AI answer.

Example:
Complaint
 -> identify customer
 -> inspect order
 -> inspect payments
 -> inspect previous tickets
 -> inspect policy
 -> determine root cause
 -> recommend action
 -> execute safe action
 -> escalate if needed
 -> generate response
 -> log result

This demonstrates autonomous multi-step support.

5. CONTRADICTION DETECTION
====================================================================

KEEP THE EXISTING CONTRADICTION ENGINE AND MAKE IT VISIBLE.

Examples:

ORDER SYSTEM:

PAYMENT SYSTEM:
Actual successful payments = ₹9,998

OR:

"Refund processed"

REFUND SYSTEM:
"Refund pending"

OR:

ORDER SYSTEM:
"Delivered"

CUSTOMER:
"Not received"

These contradictions should:
- be highlighted in the UI
- increase risk
- prevent unsafe automatic action
- trigger human review
- be included in the investigation evidence
- be recorded in the audit log

This is a major differentiator from a normal chatbot.

6. CONTEXT RETENTION
====================================================================

The official challenge specifically requires context retention.

ResolveAI must remember context during the entire case.

CONTEXT SHOULD INCLUDE:

- Customer profile
- Customer tier
- Current ticket
- Previous tickets
- Previous conversations
- Related orders
- Payment records
- Shipment records
- Product information
- Policies
- Previous actions
- Current investigation
- AI recommendation
- Approval status
- Escalation status

WHEN ESCALATED:

The human agent must receive the entire relevant context.

Do NOT make the human agent ask the customer to repeat everything.


====================================================================
7. CONTEXT-AWARE RESPONSE GENERATOR
====================================================================

The Response Agent must not generate generic responses.

BAD:

"Sorry for the inconvenience. Please wait 5–7 business days."

GOOD:

"Hi Aarav, we found two successful ₹4,999 payments against order ORD9281.
Your shipment is also six days beyond the expected delivery SLA. We have
flagged the duplicate payment for refund approval and escalated the shipment
to our logistics team. You will receive an update once the approval is
completed."

Response should consider:
- Customer name
- Current issue
- Customer history
- Actions already taken
- Company policy
- Expected next step
- Escalation status

Never claim an action was completed if it is only recommended/pending approval.


====================================================================
8. ESCALATION INTELLIGENCE
====================================================================

Do not simply escalate every difficult ticket.

Build an escalation decision.

ESCALATION SIGNALS:

- High financial value
- Fraud/security indicators
- Conflicting data
- Angry/high-risk customer
- Repeated unresolved complaints
- SLA breach
- VIP customer
- Low AI confidence
- Policy ambiguity
- Account security issue
- Multiple departments involved

ESCALATION DESTINATION:

Billing
Logistics
Technical
Account/Security
Fraud
Supervisor

EXAMPLE:

Duplicate ₹4,999 payment
+
6-day shipment delay
+
previous unresolved complaint

-> Billing + Logistics
-> Supervisor approval for refund
-> Complete context attached
